# 타임존 규칙

사용자는 한국 밖에 있을 수 있다. 시간·날짜는 앱을 실행한 기기의 로컬 타임존을 따르고 KST 를 가정하지 않는다.

- 스케줄 발화 시각(자동 발행 등)은 로컬 메서드(`setHours` 등)로. `setUTCHours`·하드코딩 `+9` 금지
- worklog "오늘"과 활동 수집 윈도우는 로컬 날짜 경계. 날짜 윈도우는 `date-window.ts` 의 로컬 기준 함수를 씀
- 발행 시각·마지막 편집 등 표시도 로컬 기준
- 타임존 설정을 추가한다면 명시적 옵션으로, 기본값은 머신 로컬 TZ
- 날짜 로직을 추가할 때 "이게 KST 를 가정하나?"를 먼저 확인
